    <Steps>
    1. **Download Package**: Click **Download Debian / Ubuntu (.deb)** above.
    2. **Install via Terminal**:
       ```bash
       sudo dpkg -i VetroLog-Linux-amd64.deb
       # If any GTK/WebKit dependencies are missing, auto-resolve with:
       sudo apt-get install -f
       ```
    3. **Launch**: Open from your application drawer or run `vetrolog` in your terminal.
    </Steps>

    ### Method B: Standalone Tarball (All Linux Distributions)
    <Steps>
    1. Download and extract `VetroLog-Linux-x64.tar.gz`:
       ```bash
       tar -xvf VetroLog-Linux-x64.tar.gz
       cd VetroLog-Linux-x64
       ./vetrolog
       ```
    </Steps>

    :::note[System Dependencies for Linux]
    VetroLog utilizes the native GTK3 and WebKit engine. Ensure your distribution has the runtime libraries:
    - **Debian / Ubuntu**: `sudo apt install libgtk-3-0 libwebkit2gtk-4.0-37` (or `libwebkit2gtk-4.1-0`)
    - **Fedora**: `sudo dnf install gtk3 webkit2gtk4.1`
    - **Arch**: `sudo pacman -S gtk3 webkit2gtk-4.1`
    :::

## 🌐 Headless Web Server Mode (Docker & Remote Machines)

If you are developing inside a headless Linux VM, remote server, or Docker container where no desktop display is available, VetroLog includes a built-in headless web server mode:

```bash
# Launch VetroLog as a local web server (default: http://localhost:8787)
./vetrolog --web

# Or specify a custom port
./vetrolog --web --port 9090

# Or prevent auto-opening the browser on startup
./vetrolog --web --no-browser
```

Simply open **`http://localhost:8787`** in your favorite browser (Google Chrome, Safari, Firefox, Edge).

## 🛠️ Building from Source

If you want to contribute or build VetroLog from the source code:

### Prerequisites
- **Go 1.22+**: [golang.org](https://go.dev/)
- **Node.js 20+** & **npm**: [nodejs.org](https://nodejs.org/)
- **Wails v2 CLI**:
  ```bash
  go install github.com/wailsapp/wails/v2/cmd/wails@latest
  ```

### Build Instructions
```bash
# 1. Clone the repository
git clone https://github.com/Tanvirul-swe/vetrolog.git
cd vetrolog

# 2. Install frontend dependencies
cd frontend && npm install && cd ..

# 3. Run in live hot-reload development mode
wails dev

# 4. Or compile a production release binary
wails build
```

The compiled native executable will be located in the `build/bin/` folder.
